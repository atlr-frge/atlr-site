# atlr.pro

Atelier Superintelligence public site. Served by GitHub Pages from `main:/docs`
at https://atlr.pro.

- `docs/` is what Pages serves. Today it holds the holding page shipped on
  30 Oct 2026 (the TiECon keynote end card pointed at atlr.pro).
- Step two, the full site, is scaffolded from the aiimaginelabs `build.py`
  pattern (`src/` to `docs/`) and staged on a branch for Sean's review before
  it replaces the holding page.
