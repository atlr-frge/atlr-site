Our own engine

From script to reviewed cut.

Conformer is Atelier’s own engine, the Bench for a production, brought into production jobs as existing IP and run inside the client’s production. Its agents make the judgments a production team makes around the AI tools, and the provenance of every shot is on file.

Script to takes

Conformer reads a screenplay, breaks it into scenes and beats, turns each beat into a shot list, holds the characters, locations and props as references every prompt draws on, and sends each shot to the right model under a spending cap.

Screenplay → scenes and beats → shot list → prompt per model → takes with their record

Checks and review

Where there is no script it works from a brief, and the takes can come from its own models or from your artists. It checks each take’s file, colour and picture and flags what a producer would reject, a person accepts or rejects each one, and the cut goes to the edit. One Conformer per production, so no client’s work can reach another’s.

Plan → make → check → approve → cut in Resolve → numbered, checksummed release
On every job

Five controls, every build.

The same five controls run in the compliance builds and the production builds, and the evidence pack that ships with an engagement is assembled from these records.

In the compliance buildIn production work
01Validation before use

Before go-live at an institution, the system runs against the institution’s own filed reports and the miss rate goes to the compliance officer.

Upscalers are scored against a reference before they touch a shot, and generative ones run per shot with sign-off.

02Human approval

Model output reaches a filing by one route only: the narrative the analyst edits and the compliance officer approves.

A person accepts or rejects every generated take, and drafts wait in a review queue until a person has seen them.

03Audit record

Every model call and human decision is written to a hash-chained audit record.

Each generated take keeps its model, prompt and settings, and its cost where the provider reports it; each accept or reject is logged with who and when.

04Release control

Every release passes automated tests and a health check before it rolls out.

Each delivery is a new numbered package, with every copy into a release checksum-checked.

05Data protection

Personal information is tokenised before any model call, and routing is restricted in code to approved Canadian regions.

Client material stays under each production’s confidentiality terms, inputs are hash-checked against their source, and review sites decrypt only in the viewer’s browser.
